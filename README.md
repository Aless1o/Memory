# Memory - Gioco di Carte

Memory è un gioco Java offline in solitario che mette alla prova la tua memoria. L'obiettivo è fare coppia tra le carte cercando di trovare tutte le corrispondenze nel minor numero di mosse possibile.

## Funzionalità

- Interfaccia grafica user-friendly
- Registro del punteggio e del numero di mosse
- Possibilità di rigiocare per migliorare il punteggio

## Installazione

1. Installa Java
2. Clona il repository 
3. Entra nella directory del progetto
4. Compila ed esegui il gioco

## Utilizzo

- Avvia il gioco eseguendolo.
- Clicca sulle carte per girarle e trovare le corrispondenze.
- Verrà mostrato in tempo reale il tuo punteggio e il numero di mosse effettuate.
- Scovate tutte le coppie si potrà decidere di continuare mantenendo il punteggio premendo il pulsante **Start** oppure di azzerare completamente il punteggio premendo **Restart**.
